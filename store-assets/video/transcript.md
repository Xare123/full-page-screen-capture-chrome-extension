# Capture Studio — quick start

A narrated walkthrough using the real Capture Studio 2.2 interface and fictional example content. The extension is demonstrated as an unpacked installation.

**0:00 — Your whole workflow. All yours.**

Capture Studio. Your free, private workspace for the pages worth saving.

**0:05 — 01 / Install the unpacked extension**

First, unzip the download. Open Chrome’s extensions page and turn on Developer mode. Click Load unpacked, choose the extracted folder, and pin Capture Studio.

**0:16 — 02 / Choose how much to capture**

Open a page and choose how much to capture: the full page, the visible area, or a selected region. Keep the page active while capture runs.

**0:26 — 03 / Capture the complete email**

Capturing a long email? Auto can find the reading pane. To pick a different area, choose scrolling area, click Full page, then select the message. Capture Studio stitches that pane from start to finish.

**0:39 — 04 / Annotate, redact, refine**

Make your point with arrows, highlights, text, or numbered steps. For sensitive details, use solid Redact. You can undo and redo as you go.

**0:50 — 05 / Put your PDF on the right page**

For a PDF, Auto suggests a paper size and orientation. Choose a standard size, or use Image-sized for one continuous page per capture part. Then export.

**1:01 — 06 / Lighter images, measured results**

Need a smaller image? Choose JPEG or WebP, then adjust the size or quality. Check export size shows the actual file size before you save.

**1:11 — 07 / Compress an existing PDF**

For an existing PDF, try Optimize to keep text and vectors. Rasterize makes image-based copies and removes searchable text and interactive features. Savings depend on the file.

**1:24 — 08 / Keep your collection local**

Your captures stay in this browser. Search, reopen, and keep creating. Export important files as a backup.

**1:31 — Every pixel. All yours.**

Capture Studio. Every pixel. All yours.
