Capture Studio 3.0.0 brings capture, recording and visual explanation into one free, local studio.

- Record a screen, window, browser tab, tab region or camera, with optional microphone, shared audio and a camera bubble. Pause, annotate, trim, mute, save frames and export short GIFs. WebM and supported native MP4 are included.
- Recognize text offline in English, Spanish and Arabic. Review, copy, download or save the result as a note.
- Keep separate notes and whiteboards, with search, templates, up to 100 pages per board, editable JSON, presentations and optional browser reminders.
- Use page presentation tools, element capture, Stop & edit, a scoped inline editor, editable drawing objects, callouts, backgrounds and browser frames.
- Retain complete long-image exports, local PDF compression, 13 common paper sizes, automatic paper selection, cropping and direct text editing. Image and PDF exports are individual files.

The verification JSON and SHA256SUMS accompanying this release identify the tested runtime, browser coverage, two independent Astra reviews and package hashes. Native encoders and shared audio depend on the browser/platform. Full-page and element captures require adding solid redactions afterward in the studio; on-page masks work in visible/region capture with Clean mode off. Google Drive OAuth integration is not included; it is also listed as unavailable in the reference extension.

To update an unpacked installation, replace the files in its existing installation folder and click Reload at `chrome://extensions`. Close older studio tabs, reopen the studio, and refresh source webpages. Keep the folder to preserve the extension identity and local library.
