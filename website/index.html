A few good questions.

Will it capture a long email?

Auto looks for a dominant scrolling reading pane when the page itself barely scrolls. For a specific pane, select “Choose scrolling area” before Full page. See the limits and tips.

Can I reduce an existing PDF?

Yes. Open the studio and choose Compress a PDF. Start with content-preserving optimization. Raster compression offers more size controls but removes searchable text and interactive content. Savings depend on the original file.

Does it work on every page?

Chrome protects internal pages, the Web Store and some built-in viewers. Incognito is disabled. Embedded frames, custom clipping and highly dynamic pages also have capture limits. Find practical workarounds.

Is there a subscription?

No. Every included capture, editing, export and compression feature is free, without a trial or watermark.
