# Capture Studio website source

Buildless public homepage, support and privacy pages for Capture Studio. Run `node scripts/build-website.mjs` from the repository root after creating the current extension and source archives. Output goes to ignored `artifacts/website/`. Public images/video come from `store-assets/`; release downloads come from `release/`. All examples are fictional.

The existing registered site is https://capture-studio-free.xare123.chatgpt.site. Use its retained Sites source checkout/identity and the supported Sites push/save/deploy workflow to update it. Do not publish tokens or authentication state. Preserve the Google ownership HTML file. The public website uses a voluntary Stripe Payment Link; no extension features require donations.
