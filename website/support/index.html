A LITTLE HELP GOES A LONG WAY.

Your studio,
working smoothly.

Setup, practical tips, and answers for Capture Studio 3.0.0.

Start here: use Chrome 147 or newer, keep the webpage active during capture, and export files you want to keep. Your library is stored in this browser profile.

Install or update

  1. Download the release ZIP and extract it into a folder you will keep.
  2. Type chrome://extensions in Chrome’s address bar and enable Developer mode.
  3. Click Load unpacked and choose the extracted folder containing manifest.json. Pin the extension in the toolbar.

To update, replace files in the same installed folder, then click Reload on the extensions page. Close old studio tabs, reopen the studio, and refresh webpages you want to capture. Keeping the same folder preserves the extension identity and local library.

Keyboard shortcuts: Alt+Shift+P captures a full page; Alt+Shift+O opens the studio. Use Option in place of Alt on Mac. Edit conflicting shortcuts at chrome://extensions/shortcuts.

Capture a long email or scrolling pane

  1. Open the message and expand any collapsed content you want included.
  2. Click the extension and leave Full-page target → Auto · page or pane selected.
  3. Choose Full page. On app layouts where the main page barely scrolls, Auto looks for a large reading pane rather than the folder list.

If Auto chooses the wrong area, select Choose scrolling area, click Full page, then click the highlighted message pane. Tab or arrow keys switch candidates, Enter captures, and Escape cancels. Main page only captures the surrounding document instead.

The pane must fit within the visible viewport and its clipping ancestors. Resize the window, close obstructing panels, or reset zoom if it reports clipping or unsupported transforms. Detection examines the top-level page DOM; embedded frames and shadow-root scrollers are not traversed. Open embedded content in its own tab or use a visible-area or region capture.

Infinite feeds or content that changes dimensions while stitching may stop a capture. This prevents saving incomplete results. A bounded preparation pass loads some lazy content, but cannot turn an infinite feed into a finite page.

Repeated or misplaced sticky bars

Smart placement keeps top bars at the top, bottom toolbars at the end, and sticky content in its normal flow. For an unusual layout, select Full-page bars → Hide fixed bars before capture. Use visible-area or region capture when a page’s overlays cannot be rearranged cleanly.

If an older email capture has faint horizontal lines across the message, update the extension, refresh the webpage, and capture it again. Version 3.0.0 fixes artifacts from toolbar shadows, replaced navigation bars and overlays. Capture uses the page’s current layout and styles. The source page and pane scroll positions restore after success, cancellation or failure. Avoid scrolling, resizing, zooming or changing the active source tab during capture. If you cancel after a complete capture has already finished saving, it stays in your library without opening an editor.

Crop after capturing

Open a capture from your library and choose Crop (C). Drag an area, then move or resize it with the handles, or enter X, Y, Width and Height. Choose Apply crop to save it or Cancel crop/Escape to leave the pixels unchanged. Copy and export wait until a pending crop is applied or cancelled.

Cropping changes the current capture part. Text remains editable and annotation layers are retained after crop or rotation; Undo restores the previous pixels during the current editing session. Export a backup of important originals before transforming them.

Edit text after placing it

Choose Text (T), click the image, and type directly on it. Enter starts a new line; Done, Ctrl/⌘+Enter or clicking outside finishes the edit, and Escape cancels. New text starts with Inter, dark charcoal, and a transparent background. Choose Select text (S), or use the text-box selector, to select it later. Drag the box to move it, drag its handles to resize and wrap it, or double-click/Edit text to change the words. Font, Color and Text size change the selected text; Background adds a color, and Transparent clears its backdrop again. Width wraps text and height grows to fit. Center brings a clipped box back into view.

With the canvas focused, arrow keys move selected text; Shift moves it 10 pixels. Enter edits it and Delete removes it. These edits autosave locally and remain editable after reopening the capture.

Right-click or copy an image

Select Pan in the editor to use the browser’s native image context menu. Right-click an editing canvas or library thumbnail for Capture Studio’s Copy image and Save image as PNG actions. These save the current capture part with flattened edits and solid redactions; library thumbnail actions use the first part. Multi-part actions are labeled current part in the editor and first part in the library. To save the full page, use Capture parts → Complete capture in the editor’s export panel. Clipboard access may require a direct click and browser permission.

Save a complete long capture as one file

Image exports download one PNG, JPG or WebP file. Choose Capture parts → Complete capture to include every original part. The part selector changes the editing preview. Current part only deliberately exports just the selected part.

The complete image automatically fits the safe browser image size using a shared uniform scale. The panel shows the actual output dimensions and, when needed, the effective scale beside the requested size. The requested range is 1–100%; automatic fitting can go below 1% for extreme long or wide captures. Whole-pixel rounding and very small sizes reduce detail. JPG/WebP quality changes the encoded size without changing dimensions.

Cropped, rotated or legacy parts with changed or unavailable original placement form one clearly labeled vertical layout in saved order, with the same scale applied to every part and padding for different widths. Undo geometry edits to restore the original placement. PDF always downloads one file containing all selected parts, with standard-paper pagination or one continuous page per part using Image-sized.

Choose a PDF layout

In Export, choose PDF. Auto recommends a paper size and orientation from the image dimensions and page estimate. You can override it with Letter, Legal, Tabloid/Ledger, A3, A4, A5, A6, B4, B5, Executive, Half Letter, 4×6 or 5×7 photo paper. Choose Image-sized for one continuous page per capture part. Check the live page estimate before saving. Standard-paper exports stop at 500 pages; choose Image-sized pages or crop a smaller area for unusually narrow images.

Compress images and PDFs

For images, export JPEG or WebP and adjust quality or resize dimensions. Check export size measures the actual encoded output. PNG is lossless and may not shrink much for photographs.

For an existing PDF, open the studio and click Compress a PDF. Start with optimization to preserve text and vector content. If you want more control, raster compression converts pages to images with resolution and quality settings.

Raster compression removes searchable text, links, form fields, annotations and digital signatures. Structural optimization may also invalidate signatures. Keep your original when these matter. Already optimized PDFs may not shrink; Capture Studio keeps the original if the result would be larger.

Password-protected PDFs must be unlocked first. Input files are limited to 100 MB; raster compression supports up to 300 pages.

Redaction and local storage

Use solid Redact for sensitive details. Pixelation is a visual effect. Screenshot/image exports, including PDFs created from captures, contain flattened pixels without editable annotation layers or hidden source images. Optimization of an existing PDF is a separate workflow and can preserve its layers. Editable originals stay in your browser library until you delete the capture.

Exports are your backup. Clearing extension data, deleting your browser profile, or uninstalling removes local projects. Image and PDF exports are flattened files, not editable project backups. Undo history lasts for the current editing session; cropping and rotation flatten current edits.

A page refuses to capture

Chrome blocks capture scripting on browser settings, the Web Store, other extensions and some built-in viewers. Incognito capture is disabled. For local file:// pages, enable Allow access to file URLs in the extension’s settings.

Captures are bounded at 120 megapixels and 160 viewports. Very large captures split into editable parts; each part is at most 24 megapixels and 16,000 pixels per side. Device memory and storage still apply.

Recording, OCR, boards and page tools

Open Record & explain for screen/window/tab/region/camera recording. The native chooser controls access. Microphone, shared audio and camera bubble are optional. Stop recording to trim, mute, restore settings, save frames or export a short GIF. WebM and supported MP4 use native encoders. Trim export runs in real time and supports up to 512 MB output; GIFs support up to 20 seconds/240 frames. Interrupted recordings retain committed chunks; verify playback and use Save original file if a partial cannot be decoded.

Extract text runs bundled English, Spanish or Arabic OCR locally. Apply or cancel a pending crop first. Review the result for recognition mistakes. OCR sees the committed, flattened image with final redactions.

Whiteboards support up to 100 pages, templates, editable JSON and progressive presentations. Redacted pages flatten in JSON exports. Notes are separate and support search, pins, Done, source links and optional browser reminders. Export important work before uninstalling or clearing browser data.

Page tools are available from the extension popup on regular websites. Use More to search commands or adjust orientation, size, names/icons and docking. Escape or a double-click on blank drawing space restores webpage interaction. Reset effects keeps drawings. Redactions remain solid even with fading ink. Guide & settings documents every tool and lets you change drawing keys or replay tips.

Selected regions can open the editor on the webpage. If the site prevents the embedded editor, the same capture opens once in a studio tab. For full-page or element capture, add solid redaction afterward in the studio. On-page masks work in visible/region capture with Clean capture off, preserving the current layout. Capture a visible region or redact the full screenshot afterward in the studio.
